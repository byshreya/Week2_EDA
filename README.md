# Week 2 Internship Project – Titanic EDA

## Project Overview

This is my Week 2 Internship Project focused on Exploratory Data Analysis (EDA) and Data Visualization using the Titanic dataset.

The analysis was performed using Python and the following libraries:
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Objectives

- Understand the structure and characteristics of the Titanic dataset.
- Identify missing values and duplicate records.
- Analyse passenger survival patterns.
- Explore the relationship between survival, gender, passenger class, age, fare, and family-related variables.
- Create meaningful visualizations to communicate the findings.
- Perform basic data transformations, aggregations, and correlation analysis.

## Dataset

The analysis was performed using the `train.csv` file from the Titanic dataset.

## Key Analysis

The project includes analysis of:

- Survival distribution
- Missing values
- Survival rate by gender
- Survival rate by passenger class
- Survival rate by passenger class and gender
- Age distribution
- Fare distribution
- Age distribution by survival
- Family-related survival analysis
- Correlation between numerical variables

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Files

- `Week2_Titanic_EDA.ipynb` – Python notebook containing the EDA and visualizations.
- `Week2_EDA.docx` – Detailed project report with visualizations and interpretations.
- `train.csv` – Dataset used for the analysis.

## Conclusion

The EDA helped identify important patterns and relationships in the Titanic dataset, particularly the differences in survival rates based on gender and passenger class. The visualizations and statistical analysis provided a clearer understanding of the factors associated with passenger survival.
